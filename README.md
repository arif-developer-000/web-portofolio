# Portofolio Arif

A modern React + Vite portfolio website with Tailwind CSS and Firebase Firestore contact form integration.

## Setup

1. Copy `.env.example` to `.env`
2. Fill Firebase config values in `.env`
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start development server:
   ```bash
   npm run dev
   ```

## Features

- Responsive minimal portfolio layout
- Sticky navbar with blur effect
- Hero, About, Portfolio, Contact, and Footer sections
- Firebase Firestore contact form storage
- Dark mode toggle
- Smooth scrolling and animated cards
